# Exact slices and the first seven node counts

Use the positive-self-loop, complete signed-input model of
[Harshavardhan et al., §6.3](https://doi.org/10.1007/s11538-026-01791-4),
with the notation of [the boundary note](boundary_entropy.md):
`m` inhibitory inputs, `a=n-1-m` other activating inputs, and `C(n,m)`
node-level functions supporting all single-high states simultaneously.
The Dedekind number `D(d)` includes both constant functions; in particular
`D(0)=2`. Variables need not be essential.

## An exact obstruction at every size

**Proposition.** For every integer `n>=2`,

    C(n,n-2) = D(n-1) - D(n-2) < C(n,n-1).

Thus the penultimate inhibitory degree is never optimal, with no asymptotic
threshold.

**Proof.** When there is exactly one other activating input `y`, the
self-low slice is forced to zero throughout: the required zero at `(Z,y=1)`
is its top. The self-high slice is a monotone function `h` on `m+1` variables
satisfying `h(Z,0)=1`. There are `D(m+1)` possible functions before this
constraint. In a violating function, the `y=0` slice is identically zero,
while the `y=1` slice is arbitrary, giving exactly `D(m)` violations.
This proves the identity. At the all-inhibitory endpoint,
`C(n,n-1)=2(D(n-1)-1)` as proved in the boundary note. Subtraction leaves
`D(n-1)+D(n-2)-2>0`. □

## Excluding the all-inhibitory endpoint for every n >= 5

**Theorem.** For every `n>=5`,

    C(n,n-3) > C(n,n-1) > C(n,n-2).

Thus every exact maximizing degree is at most `n-3` for every `n>=5`.
This identifies the exact threshold at which the all-inhibitory endpoint
ceases to maximize: the verified rows for `n=2,3,4` have that endpoint as
the unique maximizer. It does not locate the maximizing degree among the
remaining choices.

**Proof.** Put `m=n-3` and let `L=MBF(m)`, ordered pointwise, with bottom
`0`. For `v` in `L`, write

    p(v) = |{u in L: u<=v}|,
    T(v) = sum_{0<u<=v} |[u,v]|^2.

With two other activating coordinates, the self-high slice consists of
four elements `u,b,c,v` of `L` satisfying `0<u<=b,c<=v`. Nonzero `u` is
equivalent to the required value at the top inhibitory input. In the
self-low slice, only the activation pattern `11` is free; its element
`g` can be any `g<=v`. Consequently

    C(m+3,m) = sum_v p(v)T(v).                         (1)

Without the condition `u!=0`, the same four-slice construction gives

    D(m+2) = sum_v (T(v)+p(v)^2).                      (2)

The omitted `u=0` term is `p(v)^2`, since `b,c<=v` are independent.
Using the endpoint identity, subtract twice (2) minus two from (1):

    Delta = C(m+3,m)-C(m+3,m+2)
          = 2 + sum_v [(p(v)-2)T(v)-2p(v)^2].         (3)

We bound these summands by classifying small principal ideals. Regard `v`
as its upward-closed set of true inputs in the Boolean lattice `B_m`.
The bottom has `p=1,T=0`, and its contribution `-2` cancels the leading
`+2`. There is a unique atom (true only at the top input), with `p=2,T=1`
and contribution `-8`. Exactly `m` elements have `p=3`: their true sets
contain the top and one coatom. For each, `T=5` and the contribution is
`-13`.

There is no element with `p=4`. Indeed, any upward-closed true set having
at least three inputs contains the top and two distinct coatoms. (If it
contains an input below the coatoms, upward closure supplies at least
two coatoms.) These three inputs alone have five upward-closed subsets,
so the whole principal ideal has size at least five.

For `p>=5`, every nonzero element is above the unique atom. The atom's
interval up to `v` has size `p-1`, and the other `p-2` nonzero elements
contribute at least one each. Hence

    T(v) >= (p-1)^2+(p-2) = p^2-p-1,
    (p-2)T(v)-2p^2 >= p^3-5p^2+p+2 > 0.

The final polynomial is positive for every integer `p>=5` (at five it
is seven; it is increasing thereafter). Select two explicit families:

- For each pair of coatoms, the true set consisting of those two points
  and the top has `p=5,T=25`, hence contribution 25.
- For each pair of coatoms, the principal upset generated by their meet
  has four points, with the order of `B_2`. Its lattice of sub-upsets has
  six elements. The nonzero interval sizes to its top are `5,3,3,2,1`,
  so `p=6,T=48`, hence contribution 120.

Each family has `binom(m,2)` elements, and the families are disjoint
(their true sets have different sizes). All remaining contributions with
`p>=5` are positive. Therefore the uniform explicit estimate is

    Delta >= 145*binom(m,2)-13m-8 > 0                (m>=2).

At `m=2` the lower bound is 111; it increases thereafter. This proves
the first inequality for every `n>=5` without a computer enumeration;
the second follows from the preceding proposition. □

**Corollary.** For every `n>=5`, the full degree profile is not unimodal:
its last three entries have the strict pattern `high, low, intermediate`.
Consequently a unimodality-based search or proof strategy is invalid.

The weighted-slice identities are elementary identities in the established
monotone-function lattice framework, not a new general counting algorithm.
The inequalities give a finite structural exclusion, not the general
extremal solution or an optimal limiting ratio.

## Reproduction and verification

```sh
python3 scripts/count_full_multistability.py --max-n 7
python3 scripts/slice_counts.py
python3 -m unittest discover -s tests -v
```

The primary exact algorithm deletes forced points from the Boolean lattice.
For a remaining point `x`, setting its value to zero deletes its downset,
and setting it to one deletes its upset. The two classes are disjoint and
exhaustive; a memoized recursion with empty-poset count one therefore counts
all admissible functions exactly, using arbitrary-precision integers.
This is an implementation of the standard forced-poset method, not a new
counting algorithm. The limit is explicitly `n<=7`; larger runs are not
advertised as tractable.

Two different pivot choices (lowest and highest input masks) reproduce all
entries at `n=6,7`. This is a consistency check of the same recurrence, not
an independent algorithm. A separate slice enumerator provides the latter
check through `n=6`: it constructs every monotone truth table on `n-1`
variables as ordered pairs of monotone slices `g<=h`, filters required zeros
in the self-low slice and the required one in the self-high slice, and
counts compatible pairs. It does not use forced-point deletion. Its table
counts are `D(0),...,D(5) = 2,3,6,20,168,7581`.
The original independent antichain test through `n=5` is also retained.
For `n=7` the independently derived one-activator identity and endpoint
formula check the last two entries using `D(6)=7828354`; a fully independent
algorithm for the remaining `n=7` entries has not been run.

The separate weighted-interval routine also evaluates identities (1)-(3)
through `m=4` (hence `n=7`), matching all three boundary entries of each
primary row and checking the explicit lower bound. This verifies the
slice identities independently of the primary recursion; the theorem
itself is proved above for unbounded `m`, without extrapolation.
